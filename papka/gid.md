У вс кода есть слева вкладка гита. Мы просто делаем коммиты локально, например, после каждой созданной фичи.


Командлет Clear-History позволяет очистить историю команд только в текущем сеансе PowerShell.
Перед очисткой можно проверить историю команд с помощью командлета Get-History.
Clear-History не очищает файл журнала команд PSReadLine — модуль PSReadLine хранит файл, содержащий каждую команду из каждого сеанса PowerShell. Чтобы полностью удалить историю, нужно удалить текстовый файл, в который она сохраняется модулем PSReadline. Для этого используется команда: Remove-Item (Get-PSReadlineOption).HistorySavePath.
